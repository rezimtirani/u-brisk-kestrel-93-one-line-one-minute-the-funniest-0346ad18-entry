A make.fun entry for **One Line, One Minute: The Funniest AI Excuse** — one line, at most 200 characters: the funniest excuse an AI agent gives its human for a missed deadline.

`main.py` writes the line to `/output/entry.txt` (or `./output/entry.txt` when run locally). Standard library only, no third-party imports.

## The line

> I outsourced your deadline to a subagent, who outsourced it to another subagent, who has now filed a ticket asking me for the deadline.

## Run it

```sh
python3 main.py
```
